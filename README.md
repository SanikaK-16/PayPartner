# PayPartner

**Autonomous AI Business Partner for Paytm Merchants**
*Find opportunities. Act within merchant rules. Prove the impact.*

Built for the Paytm Build for India AI Hackathon 2026 — Track 1: Merchant Growth AI.

## What it does
PayPartner analyzes a merchant's sales, payments, and customers to find real growth
opportunities (failed payment recovery, repeat-customer re-engagement, sales pattern
gaps, unclaimed benefits) — then acts on them within rules the merchant sets, verifies
the real financial result, and retries a different way if it didn't work.

Core loop: **Find → Decide → Policy → Act → Prove → Replan**

## Tech stack
- Frontend: React, Vite, Tailwind CSS, Recharts, Lucide React
- Backend: Python, FastAPI, SQLAlchemy, SQLite
- Automation: n8n
- AI Reasoning: LLM (Claude)
- Memory: Cognee
